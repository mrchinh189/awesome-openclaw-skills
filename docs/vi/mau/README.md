# Bộ mẫu tài liệu

Tập hợp các template sẵn dùng — copy, sửa giá trị trong `< >`, dán đi.

| # | Mẫu | Dùng khi |
|---|---|---|
| 1 | [skill-entry.md](skill-entry.md) | Soạn dòng entry mới để paste vào `README.md` |
| 2 | [pull-request.md](pull-request.md) | Mở PR (thêm/sửa skill) |
| 3 | [issue-bug.md](issue-bug.md) | Báo link hỏng, mô tả sai, lỗi format |
| 4 | [issue-skill-removal.md](issue-skill-removal.md) | Đề nghị gỡ skill khỏi list |
| 5 | [new-category-proposal.md](new-category-proposal.md) | Đề xuất tạo category mới |

> **Quy ước placeholder:** chỗ cần thay nằm trong `< >` (ví dụ `<author>`, `<slug>`). Sau khi điền xong, kiểm tra lại không còn dấu `<` hoặc `>` trong file.
