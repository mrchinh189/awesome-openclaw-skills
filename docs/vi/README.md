# Tài liệu tiếng Việt — Awesome OpenClaw Skills

Bộ tài liệu này **không thay thế** `README.md` gốc tiếng Anh — nó bổ sung góc nhìn tiếng Việt cho người mới tham gia repo, kèm sơ đồ trực quan và hướng dẫn triển khai chi tiết.

> Repo gốc là một **"awesome list"** thuần tuý — một danh sách curate liên kết tới skill đã publish trong [openclaw/skills](https://github.com/openclaw/skills/tree/main/skills). Repo **không chứa code skill**, chỉ chứa mô tả và liên kết.

## Khi nào cần bộ tài liệu này?

- **Lần đầu mở repo** → đọc [Giải phẫu repo](01-giai-phau-repo.md) để hiểu ngay cấu trúc.
- **Muốn thêm skill** → mở [Hướng dẫn triển khai](02-huong-dan-trien-khai.md) và copy [mẫu PR](mau/pull-request.md).
- **Phát hiện link hỏng / mô tả sai** → dùng [mẫu issue](mau/issue-bug.md).
- **Đề xuất gỡ skill** → dùng [mẫu gỡ skill](mau/issue-skill-removal.md).
- **Đề xuất category mới** → dùng [mẫu category](mau/new-category-proposal.md).
